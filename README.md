# 🎥 .Spv — Synchronize Packed Video Format

> A new open video format designed for synchronized, multi-angle playback.

Created by **Darma Angelo**, a solo developer from Indonesia 🇮🇩  
`.spv` allows seamless playback of multiple video sources in perfect sync — ideal for CCTV review, multi-cam training, interactive storytelling, or POV-based film experiences.

---

## 🌟 What is `.spv`?
`.spv` (Synchronize Packed Video) is a container format that stores:
- Multiple POV video files
- Manifest metadata (`manifest.json`)
- Playback instructions (layout, default view, transitions)

Unlike `.mp4`, `.spv` is designed to **tell a story from multiple perspectives — in sync**.
